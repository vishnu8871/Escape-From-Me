# 🎮 AI Data Rush

## 🚀 Overview

**AI Data Rush** is a browser-based interactive game developed using **HTML, CSS, and JavaScript**.

The game challenges the player to collect valuable data while avoiding harmful objects, make quick decisions, and achieve the highest possible score before the timer runs out.

The game is designed around an **AI and digital-data theme**, providing a simple but engaging gameplay experience directly in a web browser.

---

## 🚀 Live Demo

Play the game online:

👉 **[Play AI Data Rush](https://vishnu8871.github.io/Escape-From-Me/)**

---

## 🎯 Objective of the Game

The main objective of AI Data Rush is to:

- Collect valuable data objects.
- Avoid harmful or incorrect objects.
- Score as many points as possible.
- Complete the challenge before the timer reaches zero.
- Try to achieve the highest score.

The player needs to react quickly and make correct decisions throughout the game.

> **Collect the right data. Avoid the wrong data. Beat the clock.**

---

## 🕹️ How to Play

### Step 1: Start the Game

Open the game in a modern web browser.

On the starting screen, click the **Start Game** button.

---

### Step 2: Understand the Instructions

Before playing, read the instructions provided by the game.

The instructions explain:

- Which objects should be collected.
- Which objects should be avoided.
- How points are calculated.
- How the timer works.
- How to interact with the game.

---

### Step 3: Play the Game

Once the game starts, the player enters the main gameplay area.

The player must identify and collect the correct data objects.

Successful collection increases the score.

---

### Step 4: Avoid Harmful Objects

Some objects are not meant to be collected.

The player must avoid these objects because they can negatively affect the score or gameplay.

The challenge is to quickly distinguish between useful and harmful data.

---

### Step 5: Watch the Timer

The game includes a countdown timer.

The player has a limited amount of time to achieve the highest possible score.

When the timer reaches zero, the game automatically ends.

---

### Step 6: View the Result

After the timer reaches zero, the gameplay ends and the result screen is displayed.

The result screen shows the player's final performance.

The player can then choose to play again and try to improve the score.

---

# 🏆 Scoring System

The game uses a score-based system.

| Player Action | Result |
|---|---|
| Collect correct data | Score increases |
| Collect high-value data | Higher score |
| Collect harmful object | Score penalty / negative effect |
| Avoid harmful objects | No penalty |
| Finish the timer | Game ends and final score is displayed |

The player should focus on collecting valuable objects while avoiding harmful ones.

---

# ⏱️ Timer

AI Data Rush is a time-based game.

The timer starts when the player begins the game.

Example:

60 → 59 → 58 → 57 → ... → 3 → 2 → 1 → 0


When the timer reaches `0`, the game ends automatically and the final result is displayed.

# 🚀 How to Run the Game

## Option 1 — Open Directly

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a modern web browser.
4. Click **Start Game** to begin.

---

## Option 2 — Using VS Code Live Server

For development, the game can be run using VS Code Live Server.

### Steps

1. Open the project folder in Visual Studio Code.
2. Install the **Live Server** extension.
3. Right-click on `index.html`.
4. Select **Open with Live Server**.
5. The game will open in your default browser.

No additional backend server is required to run the game.

---
